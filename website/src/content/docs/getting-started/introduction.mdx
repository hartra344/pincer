Pincer is a native macOS and iOS app for your [OpenClaw](https://github.com/openclaw/openclaw) Gateway.

Your gateway already serves the Control UI in a browser. Pincer is for when you want your agents in a real app instead: one that answers a global shortcut, appears in the share sheet and Shortcuts, brings exec approvals to your notifications, and keeps every gateway you use in one window. [Pincer vs the Control UI](../why-pincer/) says when each fits.

## What Pincer is (and isn't)

Pincer is a **pure client**. It connects to a Gateway you already run and uses the Gateway WebSocket protocol (v4) in the `operator` role.

- It **never** bundles, launches or embeds a Gateway.
- It only registers as a node if you turn on the opt-in [device mode](../../guides/device-mode/), and then it declares just the read-only data you check. It **never** exposes camera, screen, shell or `system.run` capabilities.

That's why you can use it on machines where the official OpenClaw app isn't allowed. [The security model](../../reference/security/) covers the details.

:::note[You need a Gateway]
Pincer doesn't run agents itself. It talks to an OpenClaw Gateway on this machine, on your network, or reachable over Tailscale. No gateway yet? You can still [try the demo](../try-the-demo/).
:::
