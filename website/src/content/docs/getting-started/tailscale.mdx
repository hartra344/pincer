[Tailscale](https://tailscale.com) is the easiest way to reach a gateway running at home from your laptop or phone, without opening ports to the internet.

<Steps>
1. **Turn on Tailscale Serve on the gateway host.** The gateway stays private to your tailnet, and Tailscale adds HTTPS:

   ```sh
   openclaw config set gateway.tailscale.mode serve
   openclaw gateway restart
   ```

   See OpenClaw's [stable HTTPS URL guide](https://docs.openclaw.ai/gateway/stable-https-url) for details.

2. **Make sure your device is on the same tailnet.** Install Tailscale on your Mac or iPhone and sign in to the same account.

3. **Add the gateway in Pincer.** On first launch choose **Get Started** (or choose **Add Gateway…** from the sidebar's **Organize** menu or <kbd>⌘</kbd> <kbd>K</kbd>). On **Find your gateway**, choose **Tailscale** and enter the address:

   - **With Tailscale Serve:** `wss://<host>.<tailnet>.ts.net`, for example `wss://my-mac.tail1234.ts.net`. Serve uses HTTPS on port 443, so leave off the port. You can type just the host name.
   - **Directly by tailnet IP:** `ws://100.x.y.z:18789`, if the gateway is bound to its tailnet IP (`gateway.bind: "tailnet"`) instead of using Serve.

4. **Sign in** with your gateway's token (`openclaw config get gateway.auth.token`) or password.

5. **Approve the device.** The first time, Pincer shows the exact command to run on the gateway host:

   ```sh
   openclaw devices approve <requestId>
   ```

   Pincer moves on by itself after you approve it. If another device is already paired with **Full Management**, you can approve it there instead, under **Gateway Settings → Devices**. See [Connect a gateway](../connect-a-gateway/) for the full walkthrough and [Devices & Nodes](../../guides/devices/).
</Steps>

<Aside type="caution" title="ws:// with a .ts.net name">
If you enter `ws://` with a `.ts.net` name, Pincer warns you. Tailscale Serve uses HTTPS, so a Serve name almost always needs `wss://`. Use `ws://` only with the tailnet IP and the gateway's port.
</Aside>

## On the go

Because the device identity and secret stay in the Keychain, Pincer reconnects whenever Tailscale is up, whether you're on home Wi-Fi or on cellular. Notifications for chats you aren't looking at arrive as they happen while Pincer is connected. On iOS, to get notifications while Pincer is closed, set up a [push relay](../../guides/push-notifications/).
